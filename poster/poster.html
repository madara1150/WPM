Description

JUST TYPE ให้ทุกคนได้ฝึกและพัฒนาทักษะการพิมพ์ เริ่มจากโปรแกรม command prompt ภาษา C และต่อยอดเป็นเว็บที่เล่นได้ทันทีบนเบราว์เซอร์

Objective

ให้ผู้ใช้เลือกระดับความยากและเวลาได้เอง ฝึกปุ่มที่พลาดบ่อย และวัดระดับตนเองจากความเร็วกับความแม่นยำที่เห็นผลชัดเจน

รู้ผลทันทีหลังพิมพ์จบ

WPM ความแม่นยำ และกราฟความเร็วรายวินาที

เกมฝนคำ

พิมพ์คำให้ทันก่อนตกถึงพื้น เก็บคอมโบคูณคะแนน

เห็นพัฒนาการของตัวเอง

สถิติ แนวโน้ม และวันที่ฝึกติดต่อกัน

How it works

  1. สแกน QR หรือเปิดเว็บ
  2. เลือกโหมด ภาษา เวลา และระดับ
  3. เริ่มพิมพ์ นาฬิกาเดินเมื่อกดปุ่มแรก
  4. ดูผล แล้วฝึกปุ่มที่พลาดซ้ำจนแม่น
